# Cargo Auctions

Тестовое задание. SPA для грузовых аукционов. Требования — docs/TASK.md.

## Схема API

openapi.auctions.v0.json — реконструкция, оригинал не предоставлен.
Всё предположительное помечено `// PROVISIONAL: причина`.
При получении настоящей: заменить файл, перегенерировать типы, чинить по компилятору.

## Конвенции

- компоненты: PascalCase.tsx, один компонент на файл
- типы DTO только сгенерированные из схемы, руками не писать
- строковые enum-значения только в shared/api, в UI импорт по имени
- компоненты работают с ViewModel, не с DTO; маппинг в entities
- комментарии не писать, кроме PROVISIONAL

## Команды

npm run dev / build / test / lint / check

## Правила работы

- коммитить после каждого завершённого шага, ветку не менять без спроса
- не добавлять функциональность, о которой не просили
