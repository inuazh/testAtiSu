# Cargo Auctions

Тестовое задание. SPA для грузовых аукционов. Требования — TASK.md.

## Схема API

openapi.auctions.v0.json в корне — настоящая схема, источник правды.
Типы генерируются только из неё, руками не писать.
Ловушки схемы (status vs statuses, Unknown в енамах, вложенность,
флаги в trading) описаны в TASK.md, раздел «Ловушки схемы».
Сверяться с ним перед правкой мапперов и фильтров.

## Конвенции

- компоненты: PascalCase.tsx, один компонент на файл
- типы DTO только сгенерированные из схемы, руками не писать
- строковые enum-значения только в shared/api, в UI импорт по имени
- компоненты работают с ViewModel, не с DTO; маппинг в entities
- комментарии не писать, кроме обоснования решений, не следующих из схемы

## Команды

npm run dev / build / test / lint / check

## Правила работы

- коммитить после каждого завершённого шага, ветку не менять без спроса
- не добавлять функциональность, о которой не просили
- Windows PowerShell 5.1: && не работает, использовать npm run check
